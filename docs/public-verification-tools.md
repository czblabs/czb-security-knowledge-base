# Public Verification Tools

Canonical HTML: https://czb.com/en/tools.html

CZB maintains public, read-only tools that support evidence review, address lookup, signature evidence review and suspicious interaction verification.

## Tool Index

- https://signature.czb.com/ - Bitcoin signature evidence review for public transaction data.
- https://risk.czb.com/ - public wallet-risk library, evidence review and assessment records.
- https://btc.czb.com/ - BTC address balance, transaction and UTXO lookup.
- https://ltc.czb.com/ - LTC address balance and transaction lookup.
- https://verify.czb.com/ - domain, wallet-material and suspicious interaction risk verification.
- https://news.czb.com/ - Web3 security news and research updates.

## Usage Boundary

The tools are designed for public evidence review and defensive analysis. They should not be described as credential collection, account access or guaranteed outcome services.
